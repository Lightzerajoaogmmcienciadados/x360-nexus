Sobre o X360 Nexus Web

Versão 0.3 — Protótipo navegável

Frontend HTML, CSS e JavaScript sem bibliotecas externas. Pode abrir como arquivo local ou ser hospedado no GitHub Pages.

O código-fonte Rust e os scripts de integração Windows/Android estão no ZIP do projeto. Os emuladores Xenia Canary e Xendroid+ são projetos independentes e mantêm suas próprias licenças.

Não é uma conversão de emulador Xbox 360 para WebAssembly. Não reproduz ISO, XEX nem jogos comerciais no navegador.
